## 真正根因（第二轮，自检全绿后定位）

- 运行时自检全绿（OS 26200 / acrylicApi ok / mica ok / transparent ok / 节电 NO /
  高对比 NO / active ok），说明不是系统策略，是代码结构问题。
- **根因 1（决定性）**：`ReactorHost.Root` 是 `ContentControl`，而 UWP
  `ContentControl` 的默认模板（SDK generic.xaml 第 7399 行起）只有 `ContentPresenter`，
  **没有任何元素 TemplateBinding 到 Background** → 设 `Root.Background` 完全不渲染。
  `Control.Background` 官方备注："只影响模板把 Background 用作模板 UI 属性输入的控制项"。
- **根因 2（类型约束）**：WinUI2 的
  `BackdropMaterial.SetApplyToRootOrPageBackground` 签名是 `(Control, bool)`，
  **只接受 Control**，`Grid`/`Border` 传不进去（会 CS1503）。
  所以不能简单把 Root 换成 Grid。
- 解法（两层结构）：外层保留 `ContentControl`（挂 Mica 附加属性），
  内层新增 `private readonly Grid _contentLayer` 作为 `Root.Content`，
  AcrylicBrush 挂 `_contentLayer.Background`，组件树挂 `_contentLayer.Children`。
  构建 0 错误。
- 教训：**UWP 里给控件设 Background 之前，先确认它的默认模板有没有绑定 Background**。
  Grid/Border 一定渲染；ContentControl 不渲染。

## 第三轮：对齐参考实现 Furry-Xiyi/UWP-Blank-Template（最终方案）

- 参考仓库 App.xaml.cs 的 `AppThemeManager.ApplyMaterial` 给出正解：
  **`Window.Current.Content` 用 `Frame`**，而不是 ContentControl：
  ```csharp
  Frame rootFrame = new Frame();
  Window.Current.Content = rootFrame;
  // 亚克力
  rootFrame.Background = new AcrylicBrush {
      BackgroundSource = AcrylicBackgroundSource.HostBackdrop,
      TintColor = tint, TintOpacity = 0.8, FallbackColor = tint };
  // Mica
  BackdropMaterial.SetApplyToRootOrPageBackground(rootFrame, true);
  rootFrame.Background = null;
  ```
- 为什么是 Frame（generic.xaml 实证）：
  - ContentControl 模板（7399 行）ContentPresenter **无 Background 绑定** → 亚克力不渲染；
  - Frame 模板（13643 行）ContentPresenter 有
    `Background="{TemplateBinding Background}"` 和 `Padding="{TemplateBinding Padding}"`；
  - Frame 继承 ContentControl → 是 Control → 满足 BackdropMaterial 的 `(Control, bool)` 签名。
  **一个元素同时满足两个约束，不需要两层结构**（上一轮的两层 Grid 方案已废弃）。
- 参考实现还做了标题栏扩展（`CoreApplicationViewTitleBar.ExtendViewIntoTitleBar = true`
  + `ApplicationView.TitleBar.ButtonBackgroundColor = Colors.Transparent`），
  否则标题栏是一条纯色带；内容下移用根 Frame 的 Padding（顶栏高度）。
- 亚克力参数照抄参考实现：TintOpacity 0.8、tint/fallback 按明暗主题取
  `#202020` / `#F3F3F3`、**不设** TintLuminosityOpacity（系统自动推算），
  并监听 `ActualThemeChanged` 刷新 tint。
- 最终改动文件：`ReactorHost.cs`（Root 改 Frame + 主题自适应 tint）、
  `ReactorApplication.cs`（新增 `ExtendIntoTitleBar`）。构建 0 错误 3 警告。
